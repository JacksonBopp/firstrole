# Use firstrole inside Claude (no install)

Works in the Claude app or claude.ai on any plan, including free. It also works in ChatGPT and Gemini.

## One message

Start a new chat, attach your resume if you have it, and send this:

```text
Read https://raw.githubusercontent.com/JacksonBopp/firstrole/main/chat/prompt.md and follow it to help me find a job.
```

Claude reads the instructions, asks you a few questions (one at a time), then searches, reads each posting in full, and gives you the few jobs that actually fit, plus a tracker table.

**If Claude says it can't open the link:** open [prompt.md](prompt.md), copy all of it, and paste it into the chat instead.

**Next time:** copy the tracker table from the end of your last chat and paste it after the message above. That way Claude remembers what you've already seen and applied to. (On a plan with Projects, save the tracker as a project file instead.)

**Things you can say:** "find more", "I applied to #2", "#3 rejected me", "show my tracker", "help me write a cover letter for #1", "prep me for the interview at #4".
